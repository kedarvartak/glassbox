# Repository Agent Instructions

All coding agents working in this repository must follow the guidelines in:

- [`agent-docs/AGENT_GUIDELINES.md`](agent-docs/AGENT_GUIDELINES.md)

Mandatory documentation rules:

- Keep `DOC.md` updated for app-level documentation.
- Keep `CHANGELOG.md` updated for all user-visible or developer-visible changes.

If a task changes behavior, APIs, commands, configuration, workflows, or architecture, update the relevant docs and changelog in the same change.
